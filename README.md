# Freedom Tasks

A planned standalone Obsidian plugin linking plain Markdown checkboxes to Full Calendar Remastered CalDAV Tasks.

Status: compatibility spike complete; implementation blocked by the public API gap documented in [COMPATIBILITY.md](COMPATIBILITY.md). No runnable plugin or release assets have been created.

Markdown task identity, mappings, and field-level sync baselines will live in versioned plugin data. Markdown will remain ordinary checkboxes. Full Calendar will own remote credentials, protocol, persistence, and calendar rendering.
